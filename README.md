# Macro Terminal

Macro Terminal is an agentic command-line assistant purpose-built for data professionals. Unlike IDE extensions, it operates autonomously in your terminal—exploring projects, querying databases, running commands, and building understanding of your codebase and data through natural language conversations.

Learn more in the [official documentation](https://getmacro.com/docs).

## Get started

Sign up for [Macro Platform](https://platform.getmacro.com) and follow the installation guide for your platform:
- [macOS Installation](https://getmacro.com/docs/terminal/macos) 
- [Linux Installation](https://getmacro.com/docs/terminal/linux)

Authenticate and start using:
```bash
macro login
```
